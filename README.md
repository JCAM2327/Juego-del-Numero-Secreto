# Juego del número secreto

Juego interactivo en HTML, CSS y JavaScript: el sistema elige un número del 1 al 10 y el usuario debe encontrarlo con pistas de mayor o menor.

**Demo:** <https://jcam2327.github.io/Juego-del-Numero-Secreto/>

## Funcionalidades

- Validación de intentos vacíos, no enteros y fuera del rango 1–10.
- Pistas de mayor/menor e historial de la ronda.
- Conteo de intentos y mejor marca guardada en `localStorage`.
- Números distintos por ronda y reinicio del ciclo después de los 10 números.
- Interfaz responsive, navegación por teclado y mensajes accesibles.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Ejecutar en local

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

```bash
npx serve .
```
